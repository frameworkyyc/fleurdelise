# Fleur de Lise Healing — website

Astro (static) → Cloudflare Workers Static Assets. Built to **Framework Brand Kit v5** ("Modern Botanical Mysticism").

## Commands
| | |
|---|---|
| `npm install` | install |
| `npm run dev` | local dev server (http://localhost:4321) |
| `npm run build` | static build to `dist/` |
| `npm run preview` | serve the build locally |
| `npm run check` | Astro type/diagnostic check |
| `npm run check:motion` | Safari-safety guard for animation CSS (also runs in every build) |
| `node scripts/build-brand-assets.mjs` | regenerate optimised logos/icons/OG image from `brand-originals/` |

## Environments
- **Staging:** the existing `fleurdelise` Worker, bound to `https://fleurdelise.frameworktools.ca` (already attached in Cloudflare). `npm run deploy:staging` builds with staging env vars and runs `wrangler deploy`. Needs `CLOUDFLARE_API_TOKEN` (Workers Scripts: Edit) + `CLOUDFLARE_ACCOUNT_ID`.
- `wrangler.jsonc` declares no routes/domains and keeps `workers_dev` / `preview_urls` off, so deploys can't create or alter domains. Production uses its own Worker/config (`wrangler.production.jsonc`, branch `main`) — see `docs/PRODUCTION-CUTOVER.md`. The old `fleurdelisehealing.com` (Wix) is not touched by this repo.
- Staging is excluded from search engines three ways: `<meta robots noindex>`, `Disallow: /` robots.txt, and an `X-Robots-Tag` response header (`dist/_headers`); the sitemap is omitted.
- **Production** — branch `main`, `PUBLIC_SITE_ENV=production` (enables indexing + sitemap in robots.txt). **Deploy only with explicit approval. DNS is not managed here.**
- **Staging / previews** — any other branch. `PUBLIC_SITE_ENV` unset ⇒ `noindex, nofollow` meta and `Disallow: /` robots (safe default).
- No secrets live in this repo. Future form/email keys go in Worker secrets.

## Structure
```
brand-originals/   Supplied logo files, untouched (source of truth — never edit)
public/brand/      Web-optimised derivatives (generated by scripts/build-brand-assets.mjs)
src/data/site.ts   Client facts & nav. Optional fields render nothing until filled.
src/styles/        tokens.css (brand tokens) + global.css (base, textures, buttons, motion)
src/components/    Header, Footer, Hero, Button, Icon, Moons, Botanical, section components
src/layouts/       BaseLayout (SEO, OG, JSON-LD, skip link, fonts)
docs/              CONTENT-TRACKER.md (internal pending info)
```

## Brand rules enforced in code
Logos are only used whole and unmodified (Dark Background Alternative on plum; textured sub-mark as a framed tile). One texture per surface. Gold text only on plum; Bronze eyebrows on light. Disclaimer in the footer. Motion is CSS-only and disabled under `prefers-reduced-motion`.
